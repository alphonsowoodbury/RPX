Scope · The build

From raw telemetry to a model you can evaluate.

RPX is a Formula 1 race companion — and, underneath it, a working miniature of an AI research-data platform. The whole vertical slice a modern data organization runs: ingestion, a lakehouse, human-judgment collection, model training, evaluation, and serving. F1 is the data. The platform is the point. All of it built in the open.

1,156 races · 1950–2026 Batch + streaming $0 / month · five clouds Six build phases One engineer, in public

The thesis

Most data projects stop at a dashboard. This one keeps going — all the way to a model that learns from human judgment and an evaluation harness that tells you whether it actually got better. That full loop, from a real-time event stream to an evaluated, served model, is the shape of the work an AI lab's data org does every day. RPX builds that loop end to end, at hobby scale but on the real tools.

Two principles hold the whole thing together. Everything is real. A streaming pipeline that processes three events isn't streaming experience — so the live tier runs against an actual race weekend, with the lag, backpressure, and replay that come with it. And each layer earns its place. The cheap, elegant version of the companion still ships and stays fast; the heavy, industry-standard machinery lives behind it, where the engineering story is.

A complete vertical slice — ingest, label, train, evaluate, serve — not another chart.
F1 telemetry is a genuine high-rate stream and seventy years of structured history. The perfect domain to build the real thing on.

Eight layers, one loop.

Data flows from a live timing feed to an evaluated model and back to the screen. Each layer does one job on industry-standard tools.

04 Human data
F1 Judgments — collecting preference

An annotation tool where people judge pairs — which overtake was better, which strategy call smarter — producing a preference dataset, with inter-annotator agreement, quality review, and versioned guidelines.

annotation UIpreference pairsinter-annotator agreementguideline versioning
05 Models · AI
The full breadth — not just an LLM

Supervised ML and time-series forecasting on the marts; reinforcement learning for strategy and the RLHF reward loop; computer vision on race imagery; clustering, anomaly detection, and embeddings. An LLM is just one head, behind a provider-agnostic gateway.

06 Evaluation
Did it actually get better?

A reproducible eval harness over predictions, the reward model, and the agent — with experiment tracking and a leaderboard, so every change is measured, not asserted.

eval harnessexperiment trackingleaderboard
07 Serving & interface
Fast static, live push, and an agent

A thin edge API and WebSocket stream feed a real-time dashboard, plus a natural-language agent that queries the platform through tools — with a deterministic rules engine as the source of truth.

Classify, then measure the classifier

A classifier — anomaly or content quality — shipped with a labeled evaluation set and honest precision/recall reporting, because a classifier without its eval set is a guess.
